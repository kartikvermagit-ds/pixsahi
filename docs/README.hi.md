# PixSahi — Hindi guide

Photo aur signature ko online form ke required size mein taiyar karo, offline.

**[App download karo](https://github.com/kartikvermagit-ds/pixsahi/releases/latest/download/PixSahi.exe)** · [Windows ZIP](https://github.com/kartikvermagit-ds/pixsahi/releases/latest/download/PixSahi-Windows.zip) · [English guide](../README.md)

## Kaise chalayen

1. `PixSahi.exe` kholo. Installer ya administrator access ki zaroorat nahi hai.
2. **Add image** se photo/signature chuno, ya image drag karke window mein daalo.
3. **Photo** ya **Signature** select karo.
4. Apne form ki **width, height aur maximum KB** bharo. Default numbers sirf examples hain.
5. **Crop to fill** mein image drag karke frame set karo. **Fit entire image** poori image rakhta hai aur zaroorat par white margins jodta hai.
6. **Prepare image** dabao. Right side ka preview aur final size dekho.
7. **Save image** se nayi file save karo. Original photo unchanged rahegi.

## Dhyan dene wali baatein

- Sab processing offline hoti hai. Image upload, account ya internet ki zaroorat nahi hai.
- JPG ki quality KB limit ke hisaab se adjust hoti hai. PNG bada ho sakta hai.
- Limit bahut chhoti ho toh app batayegi. Us waqt KB limit badhao ya dimensions kam karo.
- 1 KB = 1,000 bytes. Exact bytes bhi preview ke neeche dikhte hain.
- App sirf maximum file size set karti hai; minimum file size ke liye padding nahi karti.
- Photo/signature examples kisi exam ya portal ke official presets nahi hain. Form ke current rules khud check karo.
- Output 96 DPI metadata use karta hai. Custom DPI, background removal aur HEIC/WebP/PDF input is version mein nahi hain.
- JPG/JPEG, PNG aur BMP input supported hai; output JPG/PNG hai.

Windows 10/11 aur .NET Framework 4.5 ya newer chahiye. App unsigned hai, isliye Windows unknown-publisher warning dikha sakta hai.

Uninstall ke liye app band karke uska folder delete kar do. Export ki hui files apni saved location par rahengi.

Problem aaye toh [bug report](https://github.com/kartikvermagit-ds/pixsahi/issues/new?template=bug_report.yml) bhejo. Public issue mein personal photo ya signature upload mat karo; sample image se problem dikhao.
