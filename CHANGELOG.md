# Changelog

## 1.0.0 — 2026-10-01

First public release of PixSahi for Windows.

- Offline photo/signature preparation with exact pixel dimensions and a maximum KB limit.
- JPG quality adjustment and PNG output with explicit oversized-file errors.
- Crop dragging, zoom, reset, clockwise rotation, and fit with white margins.
- Phone-photo EXIF orientation handling and removal of source EXIF/GPS metadata on export.
- Preview decoded from the actual output bytes, with exact size shown before saving.
- Original-file overwrite protection and stale-preview invalidation.
- Executable, portable ZIP, checksums, English/Hindi guides, and automated Windows checks.

Initial limits: JPG/PNG/BMP input; JPG/PNG output; one image at a time; no minimum-size padding or custom DPI. Photo/signature defaults are examples, not official portal presets. This release is unsigned.
